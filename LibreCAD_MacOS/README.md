# LibreCAD для macOS

Современная CAD-система для macOS с интерфейсом в стиле macOS 26 "Liquid Glass"

## 🚀 Требования

- macOS 14.0 или новее
- Xcode 15.0 или новее
- Swift 5.9+

## 📦 Установка и запуск

1. Откройте файл `LibreCAD_MacOS.xcodeproj` в Xcode
2. Выберите схему LibreCAD_MacOS
3. Нажмите ⌘R (Run) для сборки и запуска

Или через терминал:
```bash
cd LibreCAD_MacOS
xcodebuild -project LibreCAD_MacOS.xcodeproj -scheme LibreCAD_MacOS build
```

## ✨ Возможности

### Интерфейс
- Современный дизайн в стиле macOS 26
- Эффект "жидкого стекла" (NSVisualEffectView)
- Полупрозрачные панели с размытием
- Нативные элементы управления macOS
- SF Symbols иконки
- Поддержка Retina дисплеев
- Полноэкранный режим

### 2D Рисование
- **Линии** - рисование прямых линий
- **Круги** - создание кругов по центру и радиусу
- **Дуги** - рисование дуг с указанием углов
- **Прямоугольники** - создание прямоугольников
- **Полилинии** - многосегментные линии
- **Текст** - добавление текстовых надписей

### Редактирование
- **Перемещение** (Move) - перемещение объектов
- **Копирование** (Copy) - копирование объектов
- **Вращение** (Rotate) - поворот объектов вокруг точки
- **Масштабирование** (Scale) - изменение размера
- **Отражение** (Mirror) - зеркальное отражение
- **Обрезка** (Trim) - обрезка объектов
- **Смещение** (Offset) - создание параллельных объектов
- **Удаление** - удаление выделенных объектов

### Слои
- Создание и удаление слоев
- Управление видимостью слоев
- Блокировка слоев
- Назначение цветов слоям
- Переключение между слоями

### Привязки (Snap)
- Привязка к сетке (Grid)
- Привязка к конечным точкам (Endpoint)
- Привязка к середине (Midpoint)
- Привязка к центру (Center)
- Привязка к пересечениям (Intersection)
- Привязка к ближайшей точке (Nearest)

### Навигация
- Zoom (масштабирование вида)
- Pan (панорамирование)
- Показать все объекты
- Координатная сетка

### Undo/Redo
- Полная система отмены операций
- История действий
- Возврат к предыдущим состояниям

### Импорт/Экспорт
- **JSON** - нативный формат сохранения
- **DXF** - импорт и экспорт (AutoCAD compatibility)
- **SVG** - импорт и экспорт векторной графики
- **PDF** - экспорт в PDF
- **PNG** - экспорт растрового изображения

## 🎨 Дизайн

Интерфейс выполнен в современном стиле macOS с использованием:
- NSVisualEffectView для эффекта стекла
- Vibrant materials для панелей
- Rounded corners для всех элементов
- Тонкие разделители
- Правильные отступы согласно HIG
- Адаптивная анимация

## 🔧 Горячие клавиши

- ⌘N - Новый документ
- ⌘O - Открыть файл
- ⌘S - Сохранить
- ⌘Z - Undo
- ⌘Shift+Z - Redo
- ⌘+ - Увеличить
- ⌘- - Уменьшить
- ⌘0 - Показать все
- Delete - Удалить выделенное
